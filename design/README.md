# Sailsforce Design Assets

All design work for the windsurfing weather app, extracted from the Task 1 + Task 2 submission PDF.

## Source

- `source/windsurfing-weather-design.pdf` — original combined Task 1 + Task 2 document (30 pages).

## Lo-fi screens

Annotated lo-fi screens that drive the Task 3 hi-fi build (`lo-fi/`):

| File | Screen |
| --- | --- |
| `00-concept-sketch.png` | Early hand-drawn concept (circular beach minimap, hourly timeline) |
| `01-main-page-annotated.png` | **Main page** — sailability meter, beach minimap, daily timeline, weather widgets |
| `02-expanded-model-view-annotated.png` | **Expanded model view** — draggable timeline, multi-source rows, confidence & spread |
| `03-locations-page-annotated.png` | **Locations** — search, favourites, nearby spots, custom location |
| `04-settings-page-annotated.png` | **Settings** — user data (weight/height/ability), units, quiver (sails/boards) |

## Storyboards

User-flow storyboards (`storyboards/`):

1. `01-expand-forecast-timeline.png` — Cole expands the compact timeline to compare models.
2. `02-change-location.png` — Cole switches from Hookipa Beach to a nearby spot.
3. `03-wind-direction-vs-beach.png` — Cole opens the wind-vs-beach widget to check onshore/offshore.
4. `04-sail-recommendation.png` — Cole taps the sail recommendation to see why it was chosen.

## Research artefacts

Materials that fed the design (`research/`):

- `brainstorming-requirements-mindmap.png` — requirements → design ideas mindmap.
- `focus-group-thematic-analysis.png` — themes pulled from the 4-person focus group, with how each maps to Cole.
- `survey-forecast-apps-used.png` — survey: which forecast apps participants use (n=11).
- `survey-boards-owned.png` — survey: number of boards owned (n=11).

## Competitors / prior art

What the design is reacting against (`competitors/`):

- `windy-app-forecast-screen.png` — Windy.app forecast screen (multi-model, but cluttered, gated by upgrade).
- `karamarans-sail-chart.png` — static sail-size table (too coarse to be useful day-of).
