SailsForce - Group 17
=====================

A sailing weather app built with React Native and Expo.


How to run
----------

1. Make sure you have Node.js installed.
2. Install dependencies:
       npm install
3. Start the app:
       npx expo start
4. From there you can run it on web, iOS simulator, or Android emulator
   (press w, i, or a respectively in the terminal).

For web specifically you can also do:
       npx expo start --web


Libraries used
--------------

- Expo (v54) - framework for building the React Native app
- React Native (0.81) + React (19.1) - UI framework
- React Native Maps - map display for beach/spot selection
- NativeWind + TailwindCSS - utility-first styling (Tailwind but for React Native)
- Lucide React Native - icon set
- React Native Reanimated - animations
- React Native SVG - SVG rendering
- AsyncStorage - local persistent storage
- TypeScript - type checking
- Prettier - code formatting
